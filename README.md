# Software Engineering CommBank Goal Tracker

This repository contains the frontend and backend codebase for the CommBank Goal Tracker application, completed as part of the Software Engineering task series.

## Project Structure
- **commbank-web**: The React frontend application.
- **CommBank-Server**: The ASP.NET Core backend server.

## Tasks Completed
- **Task 1 & 2**: Implemented UI enhancements and fixed frontend icon styling.
- **Task 3**: 
  - Added the `updateGoal` PUT request to the frontend API layer (`lib.ts`).
  - Finished implementing the `pickEmojiOnClick` event handler in `GoalManager.tsx` to call the update API when the user updates the goal icon.
- **Task 4**: 
  - Wrote a unit test (`GetForUser`) in `GoalControllerTests.cs` to fully cover the `GetGoalsForUser` route on the backend server, verifying the response matches expectations.
- **Task 5**: Structured the workspace and initialized Git control.

Designed with modern development practices in mind, this repository showcases a clean implementation optimized for scalability and readability.

## ⚙️ Getting Started & Installation

### 📋 Prerequisites
Ensure you have the runtime environment and managers installed for **Unknown**:
*   For JS/TS: **Node.js (v18+) & NPM**
*   For Python: **Python 3.10+ & pip**
*   For Flutter: **Flutter SDK**
*   For C#/.NET: **.NET SDK (v6.0+)**

### 💻 Installation Walkthrough

1. Clone the repository to your local workspace:
   ```bash
   git clone https://github.com/karthikk20234119-cmd/Software-Engineering.git
   ```
2. Navigate into the project folder:
   ```bash
   cd Task3
   ```
3. Initialize the development environment and install dependencies:
   * **NodeJS**: `npm install`
   * **Python**: `pip install -r requirements.txt` (or activate your virtual environment first)
   * **Flutter**: `flutter pub get`
   * **.NET**: `dotnet restore`

4. Launch the application / script:
   * **NodeJS Dev Server**: `npm run dev`
   * **Python Core Script**: `python main.py` or `python app.py`
   * **FastAPI Server**: `uvicorn main:app --reload`
   * **Flutter Application**: `flutter run`
   * **.NET Core Solution**: `dotnet run`
