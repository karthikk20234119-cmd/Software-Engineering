# Software Engineering CommBank Goal Tracker

This repository contains the frontend and backend codebase for the CommBank Goal Tracker application, completed as part of the Software Engineering task series.

## Project Structure
- **commbank-web**: The React frontend application.
- **CommBank-Server**: The ASP.NET Core backend server.

## Tasks Completed
- **Task 1 & 2**: Implemented UI enhancements and fixed frontend icon styling.
- **Task 3**: 
  - Added the `updateGoal` PUT request to the frontend API layer (`lib.ts`).
  - Finished implementing the `pickEmojiOnClick` event handler in `GoalManager.tsx` to call the update API when the user updates the goal icon.
- **Task 4**: 
  - Wrote a unit test (`GetForUser`) in `GoalControllerTests.cs` to fully cover the `GetGoalsForUser` route on the backend server, verifying the response matches expectations.
- **Task 5**: Structured the workspace and initialized Git control.
